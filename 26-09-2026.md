## Python Interview Questions and Answers

### 1. What is Python?

**Answer:** Python is a high-level, interpreted, general-purpose programming language created by Guido van Rossum in 1991. It emphasizes code readability and simplicity, using English-like syntax that makes it easy to learn and understand. Python supports multiple programming paradigms including procedural, object-oriented, and functional programming. It is dynamically typed and uses automatic memory management through garbage collection.

---

### 2. What are its features?

**Answer:** Key features of Python include:
- **Simple and Readable Syntax**: Easy-to-understand code structure
- **Interpreted Language**: Code executes line by line without compilation
- **Dynamically Typed**: Variables don't require explicit type declaration
- **Object-Oriented**: Supports classes, inheritance, and polymorphism
- **Functional Programming**: Supports lambdas, map, filter, reduce
- **Extensive Libraries**: Rich standard library (NumPy, Pandas, Django, Flask)
- **Cross-Platform**: Runs on Windows, Linux, macOS, etc.
- **Memory Management**: Automatic garbage collection
- **Indentation-Based**: Uses whitespace for code blocks
- **Versatile**: Supports web, data science, AI, automation, scripting

### 11. How does Python work internally?

**Answer:** Python's internal workflow:
1. **Lexical Analysis**: Source code is tokenized into lexical elements
2. **Parsing**: Tokens are converted into an Abstract Syntax Tree (AST)
3. **Semantic Analysis**: AST is validated for correctness
4. **Compilation**: AST is compiled into bytecode (.pyc files)
5. **Interpretation**: Python Virtual Machine (PVM) interprets bytecode line by line
6. **Execution**: Bytecode instructions are executed by the interpreter
7. **Memory Management**: Garbage collector manages memory allocation/deallocation

This is why Python is called a "compiled and interpreted" language.

### 13. What is indenting in Python and why was it introduced (compared to other languages using semicolons or braces)?

**Answer:** 

**What is Indentation?**
Indentation refers to the leading whitespace (spaces or tabs) at the beginning of a line. In Python, indentation is **mandatory** and defines code blocks (functions, loops, conditionals, classes).

**Why was indentation introduced?**
- **Enforces Readability**: Forces clean, consistent code structure
- **Eliminates Redundancy**: No need for braces {} or semicolons ;
- **Philosophy**: "Readability counts" (Zen of Python)
- **Reduces Errors**: Blocks are visually clear and unambiguous
- **Simpler Syntax**: Less cluttered code appearance

**Example:**
```python
# Without indentation (invalid)
for i in range(5):
print(i)  # SyntaxError

# With indentation (correct)
for i in range(5):
    print(i)  # Correct - prints 0 to 4
```

**Comparison with other languages:**
```javascript
// JavaScript uses braces
for (let i = 0; i < 5; i++) {
    console.log(i);
}

// C uses semicolons and braces
for (int i = 0; i < 5; i++) {
    printf("%d\n", i);
}

// Python uses indentation only
for i in range(5):
    print(i)
```

### 15. What are variables in Python and how do they differ from other programming languages?

| Feature | Python | Java | C++ | JavaScript |

### 17. What are functions in Python and how do they differ from other backend programming languages? (Detailed explanation with syntax and examples)

**Answer:**

**What are Functions?**
Functions are reusable blocks of code that perform a specific task. They help organize code, reduce redundancy, and improve maintainability.

**Python Function Syntax:**
```python
def function_name(parameters):
    """Docstring explaining function"""
    # Code block
    return value  # Optional
```

**Basic Examples:**

```python
# Example 1: Simple function without parameters
def greet():
    print("Hello, World!")

greet()  # Output: Hello, World!

# Example 2: Function with parameters
def add(a, b):
    return a + b

result = add(5, 3)  # Output: 8

# Example 3: Function with default parameters
def greet_person(name="Guest"):
    return f"Hello, {name}!"

print(greet_person())           # Output: Hello, Guest!
print(greet_person("Alice"))    # Output: Hello, Alice!

# Example 4: Function with *args (variable arguments)
def sum_all(*args):
    return sum(args)

print(sum_all(1, 2, 3, 4))      # Output: 10

# Example 5: Function with **kwargs (keyword arguments)
def print_info(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")

print_info(name="John", age=25, city="NYC")
# Output:
# name: John
# age: 25
# city: NYC

# Example 6: Function with return multiple values
def get_coordinates():
    return 10, 20

x, y = get_coordinates()
print(x, y)  # Output: 10 20

# Example 7: Lambda functions (anonymous)
square = lambda x: x ** 2
print(square(5))  # Output: 25
```

**Comparison with other languages:**

| Feature | Python | Java | C++ | JavaScript |
|---------|--------|------|-----|-----------|
| Syntax | `def func():` | `public void func()` | `void func()` | `function func() {}` |
| Return Type | Inferred | Required | Required | Inferred |
| Parameters | Type optional | Type required | Type required | Type optional |
| Default Parameters | Yes | No (use overloading) | Yes | Yes |
| *args Support | Yes | No | Variadic templates | Yes (rest params) |
| **kwargs Support | Yes | No | No | Yes (object destructure) |
| Lambda Support | Yes | Yes (Java 8+) | Yes | Yes |
| Decorators | Yes | Annotations | No | Yes |

**Python Function Examples with Details:**

```python
# Example: Complete calculator function
def calculate(operation, num1, num2):
    """
    Performs mathematical operation on two numbers.
    
    Args:
        operation (str): '+', '-', '*', '/'
        num1 (float): First number
        num2 (float): Second number
    
    Returns:
        float: Result of operation
    
    Raises:
        ValueError: If invalid operation
        ZeroDivisionError: If division by zero
    """
    if operation == '+':
        return num1 + num2
    elif operation == '-':
        return num1 - num2
    elif operation == '*':
        return num1 * num2
    elif operation == '/':
        if num2 == 0:
            raise ZeroDivisionError("Cannot divide by zero")
        return num1 / num2
    else:
        raise ValueError(f"Unknown operation: {operation}")

# Usage
print(calculate('+', 10, 5))    # Output: 15
print(calculate('*', 4, 3))     # Output: 12
print(calculate('/', 20, 4))    # Output: 5.0
```

**Java Equivalent:**
```java
public static double calculate(String operation, double num1, double num2) {
    switch(operation) {
        case "+": return num1 + num2;
        case "-": return num1 - num2;
        case "*": return num1 * num2;
        case "/": 
            if (num2 == 0) throw new ArithmeticException("Division by zero");
            return num1 / num2;
        default: throw new IllegalArgumentException("Unknown operation");
    }
}
```

**C++ Equivalent:**
```cpp
double calculate(std::string operation, double num1, double num2) {
    if (operation == "+") return num1 + num2;
    else if (operation == "-") return num1 - num2;
    else if (operation == "*") return num1 * num2;
    else if (operation == "/") {
        if (num2 == 0) throw std::runtime_error("Division by zero");
        return num1 / num2;
    }
    throw std::invalid_argument("Unknown operation");
}
```

### 18. What are the types of functions in Python? What are arguments and parameters?

**Answer:**

**Types of Functions in Python:**

**1. Built-in Functions** (Pre-defined in Python)
```python
print()         # Output text
len()           # Get length
type()          # Check data type
int()           # Convert to integer
str()           # Convert to string
sum()           # Sum of iterable
max()           # Maximum value
min()           # Minimum value
sorted()        # Sort iterable
range()         # Generate range
```

**2. User-defined Functions** (Created by programmers)
```python
def greet(name):
    return f"Hello, {name}!"

def calculate_area(radius):
    import math
    return math.pi * radius ** 2
```

**3. Lambda Functions** (Anonymous, single-line)
```python
square = lambda x: x ** 2
add = lambda x, y: x + y

print(square(5))        # Output: 25
print(add(3, 4))        # Output: 7
```

**4. Recursive Functions** (Call themselves)
```python
def factorial(n):
    if n <= 1:
        return 1
    else:
        return n * factorial(n - 1)

print(factorial(5))     # Output: 120
```

**5. Generator Functions** (Yield values)
```python
def countdown(n):
    while n > 0:
        yield n
        n -= 1

for num in countdown(3):
    print(num)          # Output: 3, 2, 1
```

**6. Decorator Functions** (Modify other functions)
```python
def my_decorator(func):
    def wrapper():
        print("Before function call")
        func()
        print("After function call")
    return wrapper

@my_decorator
def say_hello():
    print("Hello!")

say_hello()
# Output:
# Before function call
# Hello!
# After function call
```

**Parameters vs Arguments:**

| Aspect | Parameter | Argument |
|--------|-----------|----------|
| Definition | Variable in function definition | Actual value passed to function |
| Location | In function definition | In function call |
| Example | `def func(x):` → x is parameter | `func(5)` → 5 is argument |
| Timing | Defined when function created | Provided when function called |
| Count | Should match arguments | Should match parameters |

**Examples:**

```python
# Parameters: a, b (in definition)
def add(a, b):
    return a + b

# Arguments: 5, 3 (in function call)
result = add(5, 3)
```

**Types of Parameters/Arguments:**

**1. Positional Parameters/Arguments**
```python
def greet(first_name, last_name):
    print(f"Hello, {first_name} {last_name}!")

# Positional arguments (order matters)
greet("John", "Doe")         # Output: Hello, John Doe!
greet("Doe", "John")         # Output: Hello, Doe John! (wrong order)
```

**2. Default Parameters**
```python
def greet(name="Guest"):
    print(f"Hello, {name}!")

greet()                      # Output: Hello, Guest!
greet("Alice")               # Output: Hello, Alice!
```

**3. Keyword Arguments**
```python
def greet(first_name, last_name):
    print(f"Hello, {first_name} {last_name}!")

# Keyword arguments (order doesn't matter)
greet(last_name="Doe", first_name="John")  # Output: Hello, John Doe!
greet(first_name="Alice", last_name="Smith")  # Output: Hello, Alice Smith!
```

**4. *args (Variable Positional Arguments)**
```python
def print_args(*args):
    for arg in args:
        print(arg)

print_args(1, 2, 3, "hello")  # Prints each argument on new line
# Output:
# 1
# 2
# 3
# hello
```

**5. **kwargs (Variable Keyword Arguments)**
```python
def print_kwargs(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")

print_kwargs(name="John", age=25, city="NYC")
# Output:
# name: John
# age: 25
# city: NYC
```

**6. Combining All Types**
```python
def full_function(a, b, *args, c=10, **kwargs):
    print(f"Positional: a={a}, b={b}")
    print(f"Args: {args}")
    print(f"Keyword with default: c={c}")
    print(f"Extra keywords: {kwargs}")

full_function(1, 2, 3, 4, c=20, x=100, y=200)
# Output:
# Positional: a=1, b=2
# Args: (3, 4)
# Keyword with default: c=20
# Extra keywords: {'x': 100, 'y': 200}
```
